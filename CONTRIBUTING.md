# Contributing to OpenIris

Thank you for helping improve OpenIris! Bug reports, questions, documentation and code are all
welcome.

## Reporting problems

Open an [issue](https://github.com/ocular-motor-lab/OpenIris/issues) with the OpenIris version
(**Help > About**), the eye tracking system you use, what you did, what happened, and the log (see
[Troubleshooting](docs/user-manual/troubleshooting.md)).

## Contributing code or documentation

1. Read [Contributing](docs/plugin-development/contributing.md) in the documentation: how to build
   OpenIris, run the tests, and what to watch for when changing image processing.
2. Make your change on a branch of your fork, keep the documentation in `docs/` up to date with it,
   and open a pull request.
3. GitHub builds your pull request and runs the tests. A maintainer will review it.
