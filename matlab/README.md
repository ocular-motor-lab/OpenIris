# MATLAB tools for OpenIris

| File | What it is |
| --- | --- |
| `OpenIrisMatlabClient.m` | Controls OpenIris through its web API: recording, events, data, settings, calibration, downloading files. Works on any system, no DLL needed. |
| `OpenIrisTCP.m` | Controls OpenIris with its text commands over TCP. |

How to use them, and the commands and data they give: [Remote control](../docs/user-manual/remote-control.md).
To read the data files: [The data file](../docs/user-manual/data-file.md).
